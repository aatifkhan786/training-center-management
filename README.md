Training Center Management

Project Description:
This is a web-based Training Center Management system that helps in managing students, trainers, courses, enrollments, attendance, and fees. The website allows admins to create and manage courses, register students, assign trainers, track attendance, and manage payments. It is built mainly using PHP, with HTML for the frontend and a small part in Hack.

Technologies Used:

PHP (Backend)

HTML/CSS (Frontend)

Hack (Optional/Performance)

MySQL (Database)

Features:

Admin, Trainer, and Student roles

Course creation and management

Student registration and enrollment

Attendance tracking

Fee management
